## 4. 为什么其余 14 个不关

- **真机 / ADR-0013 禁跑令**（`EXEC-02/03/05`、`EXE-05`、`EDT-09`）：禁跑令授权仍归大师，AI 不得代判；
- **真实浏览器**（`UIX-04`、`EXE-04`、`EDT-03`）：截图基线、WebSocket 端到端、Playwright E2E 需要真实浏览器逐页跑，本机静态断言不能替代；
- **真账号 / 真库**（`IAM-05`、`EDT-04/05`、`HRD-01`、`EXE-02`）：HTTP 全链路与 MariaDB 唯一键真实并发压测需要起服务 + 真实凭据 + 真库；`EXE-02` 还与 **G4 未判过**直接相关；
- **CI runner**（`WS-05`）：self-hosted runner 未注册，三绿无法验证。

这些包**不是「没做」**，而是「实现与本机证据齐、但验收所需的现场条件不具备」。把它们在台账上保持 `待验` / `待现场`，比批量改成 `已完成` 更接近事实。
