### 2.2 W1 后端（3 个新服务 + 3 个新单测类）

- `HealthController`：`/healthz` 存活探针**不查库**（避免 DB 抖动触发无意义重启）、`/api/health` 就绪探针查 `SELECT 1`，DB 异常返回 `DEGRADED` 而非 500；
- `SystemSettingService`：平台级 `system_setting` / 项目级 `project_setting`（**V1 基线已有两张表，不新增表**）；白名单 + 数值范围 + `ai.enabled` 布尔 + `kernel.default` 枚举校验；`entry.port` 只读；每次变更写 `audit_log`；平台写入仅 admin，项目写入先 `access.requireProjectAccess()`；
- `BuildInfoService`：读 `build-info.properties`（`scripts/gen_build_info.py` 由 pom / package.json / git HEAD 生成 23 项依赖），无产物时 `source=runtime` **不伪装**；四项自检 DB / 执行器 / 内核 / AI CLI；
- `WebConfig` 放行 `/api/health`；`scripts/build.sh` 构建前自动生成构建信息；`.gitignore` 排除该产物。
