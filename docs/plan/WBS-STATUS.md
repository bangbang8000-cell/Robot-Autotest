## 更新方式

- **AI**：认领时改 `进行中`；自检通过、开 PR 后改 `待验`（附证据路径）；**不得**自行改 `已完成`。
- **人**：合并 PR 后改 `已完成`，并把证据填实（命令或文件路径）。
- **汇总行**：每次改动后同步四个计数，别让它过期——它是所有人第一眼看的东西。
