## 1. 测试目标

### 1.1 三件事

| # | 要证明 | 为什么 |
|---|---|---|
| 1 | **到点一定会跑，且只跑一次** | 不跑 = 漏测；跑两次 = 重复占设备、报告打架 |
| 2 | **自动跑的运行也是「可对外」的** | 否则自动化程度越高，可交付报告越少（PRD §1.2） |
| 3 | **失败要能解释** | 计划没跑，必须能在触发日志里查到「为什么没跑」 |

### 1.2 本版的测试难点：时间

调度是**唯一必须等真实时间流过**的模块。这里有两种做法：

| 做法 | 问题 |
|---|---|
| 把 cron 改成「每分钟」测 | 只验证了「能跑」，没验证「准」 |
| 只做单元测试（mock 时钟） | 验证了算法，没验证「在真实 JVM + DB 下不会被重复触发」 |

**本版两者都做**：单元测试用固定时钟覆盖边界日历；7 天真实观测覆盖「准 + 不重复 + 重启恢复」。

### 1.3 不测什么

- 通知（不做）
- 多节点调度（单机）
- Gitea 部署本身（若上，属另一件事）

## 3. cron 与调度

### 3.1 日历边界（单元测试，固定时钟）

| ID | 用例 | 期望 |
|---|---|---|
| TC-v0.6-101 | 每天 08:00 | 连续 5 次均为 08:00:00 |
| TC-v0.6-102 | 每月 31 日 | 2 月跳过，4 月跳过，1 月执行 |
| TC-v0.6-103 | 2 月 29 日 | 平年跳过，闰年执行 |
| TC-v0.6-104 | 每 5 分钟 | 09:00/09:05/09:10 正确 |
| TC-v0.6-105 | 跨零点 `59 59 23 * * ?` | 次日 00:00 前触发的下一次正确 |
| TC-v0.6-106 | 非法表达式 | `0 0 25 * * ?` 被拒，提示小时范围 |
| TC-v0.6-107 | 表达式含年字段 | 明确报「不支持年字段」，不静默忽略 |
| TC-v0.6-108 | **时区不随系统变** | 把 JVM `TZ` 改为 `UTC`，触发时间仍按 `Asia/Shanghai` |
| TC-v0.6-109 | 预览 5 次 | 与手工计算一致 |

### 3.2 触发与防重

| ID | 用例 | 期望 |
|---|---|---|
| TC-v0.6-110 | 单次触发 | 到点后 ≤30 s 内创建 run，`trigger_type=schedule` |
| TC-v0.6-111 | **并发 tick** | 同时调用两次 tick → 只创建 1 个 run（行锁生效） |
| TC-v0.6-112 | **重启后不重复** | 触发前 kill 进程再起 → 不产生第二个 run |
| TC-v0.6-113 | 重叠跳过 | 上一轮 running 时新触发 → `skipped(overlap)`，有日志 |
| TC-v0.6-114 | 错过不补 | 停服 20 分钟（错过一次）→ 恢复后不跑，记 `skipped(misfire)` |
| TC-v0.6-115 | 补跑开关 | 计划设 `catchUp=true`，停服 20 分钟 → 恢复后补跑 1 次（不补多次） |
| TC-v0.6-116 | 停用计划 | 停用后跨过触发点，无新 run，无报错 |
| TC-v0.6-117 | 跳过也要推进 next_run_at | 连续跳过 3 次后，`next_run_at` 仍按 cron 前进（不堆积） |

### 3.3 7 天真实观测（G6 的核心证据）

| 项 | 要求 |
|---|---|
| 计划 | 3 个：每日 08:00、每小时、每 5 分钟（快节奏用于发现偶发） |
| 时长 | 连续 7 天 |
| 记录 | 每个触发点的「计划时间 / 实际时间 / 偏差 / 结果」 |
| 判据 | 成功率 **100%**；偏差 **≤30 s**；无重复；无堆积 |

**观测期间的检查项**：跨周末（若有）、平台重启一次（模拟运维）、手动改一个计划的 cron（验证重算）。

## 11. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 把 cron 改每分钟当「验收」 | 没验证「准」，只验证「跑」 | 7 天真实观测不可省 |
| 只测单次触发不测并发 | 重启/多线程下重复触发 | 111/112 必测 |
| 忘测「跨天口径」 | 昨晚成功当成今天通过，依赖形同虚设 | 307 必测 |
| metadata 只测字段不测导出 | 字段对了但导不出（长度/格式问题） | 208 必测 |
| 群晖回写被假设成功 | 用户以为有状态，实际没有 | 411 断言 `not_supported` |
| 观测期占用真实设备 | 影响其他测试 | 观测用轻量用例集 + 独立测试项目 |
