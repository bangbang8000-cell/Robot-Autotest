## 1. 测试目标

### 1.1 这一版测的是「敢不敢给别人用」

| # | 要证明 | 判据 |
|---|---|---|
| 1 | 权限没有漏 | 112 格逐格有结论，`N/A` 有理由 |
| 2 | 改了什么查得到 | 10 类关键操作 100% 留痕 |
| 3 | 出事退得回 | 回滚演练 **RTO ≤30 分钟**，数据一致 |
| 4 | 换人接得住 | 新人只给手册能独立重启与恢复 |
| 5 | 长期跑得住 | 24 h 无崩溃；观察窗 4 周成功率 ≥99% |

### 1.2 本版的一条特殊纪律：**不接受自我判定**

前面版本的验收可以靠脚本输出。这一版有三件事**必须由「不知道答案的人」判定**：

| 事项 | 谁判 | 为什么 |
|---|---|---|
| 权限矩阵 | 人逐格签字 | 矩阵漏一格，AI 也会说「全绿」 |
| 手册可执行性 | 没参与运维的人 | 写手册的人永远觉得「这不很明显吗」 |
| UAT | 使用方 | 内部人测出来的「好用」不算数 |

### 1.3 不测什么

- 新功能（本版没有）
- 高可用/故障切换（单机，不做）
- 第三方渗透（运营期）

## 4. 权限矩阵（HRD-01）

### 4.1 结构

4 角色 × 7 资源 × 4 动作 = **112 格**，每格 `ALLOW` / `DENY` / `N/A`。

### 4.2 用例

| ID | 用例 | 期望 |
|---|---|---|
| TC-v1.0-101 | 矩阵逐格执行（参数化） | 112 格全部符合 YAML 定义 |
| TC-v1.0-102 | `ALLOW` 格**真能拿到数据** | 200 且响应体含预期数据（不是空集） |
| TC-v1.0-103 | `DENY` 格**不泄露存在性** | 403，响应体不含该资源名/数量 |
| TC-v1.0-104 | `N/A` 格有理由 | YAML 中 `reason` 非空 |
| TC-v1.0-105 | 无项目成员身份 | 403 或空集，**不 500** |
| TC-v1.0-106 | 导出矩阵 CSV | 113 行（含表头），每格有实际结果 |
| TC-v1.0-107 | 矩阵与实际代码一致 | 权限注解新增/删除时矩阵同步（CI 检查注解清单与 YAML 一致） |

**TC-v1.0-102 为什么必须存在**：只测 `DENY` 的话，一个「全拒」的实现也能过。必须同时证明「该给的真给了」。

### 4.3 人工签字

导出 CSV 打印，由 silence 逐行勾「确认」。**AI 不得代签**。签完扫描进证据目录。

## 8. 回滚演练（HRD-04）

### 8.1 用例

| ID | 用例 | 期望 |
|---|---|---|
| TC-v1.0-501 | dry-run 完整性 | `rollback.sh --dry-run` 打印全部命令，无遗漏 |
| TC-v1.0-502 | **回滚 RTO** | 从开始到「抽样验证通过」**≤30 分钟** |
| TC-v1.0-503 | 回滚后可用 | 登录、看历史报告、跑一条用例，三项全过 |
| TC-v1.0-504 | 数据一致性 | 回滚前后 `run` 记录数一致（若 schema=keep）；审计不丢 |
| TC-v1.0-505 | schema=down 的数据交代 | 执行 down 后，被删表的数据在 dump 中可恢复（验证一次） |
| TC-v1.0-506 | 回滚失败可重入 | 中途 `Ctrl-C` 后重跑，停在明确状态，不产生半截数据 |
| TC-v1.0-507 | 升级路径 | 从 v0.6 升到 v1.0 后自检清单全过 |

### 8.2 RTO 计时方法

```
t0 = 执行 rollback.sh 的第一秒（人为按下）
t1 = 抽样验证最后一项通过的那一刻
RTO = t1 - t0
```

**必须分步记录**（备份/停服部署/起服检查/抽样），否则超时了不知道慢在哪。

## 14. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 权限矩阵「全绿」但漏格 | 上线后有越权 | CSV 逐行由人签字；CI 检查注解与 YAML 一致 |
| 只测 DENY 不测 ALLOW | 全拒实现也能过 | TC-v1.0-102 强制「真能拿到数据」 |
| 手册由写的人验证 | 卡点发现不了 | 换人执行，一提问即记卡点 |
| 回滚只做代码回退 | 演练轻松但真出事时 schema 不兼容 | 两条路径（keep/down）都演练，down 只做一次但要真做 |
| 观察窗凑数 | 「4 周 20 次」靠本地用例凑满 | 过滤 `dut IS NOT NULL` 且非回放 |
| 观察窗中途出 P0 但不想重计 | 带病转运营 | 写死「P0 即重置」，由大师确认 |
| UAT 由内部人代测 | 真实用户视角缺失 | 代测必须标注「代执行」，不得冒充使用方签字 |
