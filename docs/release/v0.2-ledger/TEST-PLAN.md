## 3. 越权测试集（IAM-05，20 条，本版核心）

### 3.1 设计原则

- **只走 HTTP，不调 Service**。注解拦不住的东西，只有真发请求才测得出来。
- **每条都要断言「拒绝」且「不泄露」**：403 而非 500，响应体不含资源标题、存在性、数量。
- **必须有正向对照**：同一请求换个合法身份要成功，否则「全拒」也能骗过测试。

## 13. 增量：多项目中心与体验基线测试（2026-11-04）

**总原则**：这批需求的缺陷有两类特别危险，测试设计主要针对它们。

1. **「看起来对但实际错」**：亮色下某个卡片其实是深色块（不影响功能，但一眼就是没做完）；
   批量审批显示「成功 3 条」而实际只改了 2 条。→ 每条都要**外部对照**（截图逐页看 / 查库核数）。
2. **「升级把人家的数据弄没了」**：资产池迁移只要漏回填一步，各项目资产就全空。
   → 必须先做**升级前后快照比对**，不接受「迁移脚本退出 0 就算成功」。

**环境**：`robot_it`（真库）+ 本地 5173/8082 联调；资产池用例需**独立空库**跑一遍全量迁移。
