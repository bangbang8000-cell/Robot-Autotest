# UX-04 步骤 0：两页试点隔离工程

**状态**：供试点评审的**输入物**，不是评审结论，也不是全量迁移。
**边界**：不并入 `frontend/`、不改主仓 `package.json`、不改任何现有视图/样式/依赖；
本目录只作为 `docs/design/` 下的存档与复现材料，不参与主仓 vite 构建。

## 为什么有这个目录

`美术体系-开发与测试计划-20261104.md` §2.2 步骤 0 的产出栏写的是「试点分支 + 对比报告」，
验收栏才写「试点评审通过后本表后续步骤才开工」。即**两页试点是评审对象本身**，
不是评审通过之后才做的步骤 1~8。2026-11-04 晚的《试点评审准备清单》把步骤 0 也一起冻结了，
导致没有可评的实物，本目录纠正这一处倒置。

步骤 1（lucide）、2（打包字体）、3（token 化）、4（主题对接层）、5（组件映射）、
6（六预设强调色）、7（styleguide）、8（体积预算脚本）**仍然全部未开工**。

## 复现

```bash
cd docs/design/pilot
npm install                 # 只装本目录依赖
python3 check_pilot.py       # 静态守门：0 硬编码色值 / token 单向派生
bash measure.sh              # 两候选分别 build + gzip 体积实测
```

预览：`npx vite --config vite.naive.config.ts`（element 同理），手工切亮/暗 × 中/英采四态截图。
