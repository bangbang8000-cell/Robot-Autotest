### 3.2b UX-04b（逐页迁移）· 视图级回归测试（2026-11-05 追加）

逐页把原生元素换成库组件，**四态截图只能人看，而人看不覆盖「接线」**：迁移中最容易坏的不是样式，
是「按钮 → 状态 → 面板」这类本节重新连的线，`vue-tsc` 与构建都发现不了。因此每迁一页补一份
视图级 spec，用 `createApp(CasesView).mount(div)` 真挂载（不引入 `@vue/test-utils`）。

| ID | 用例 | 层级 | 期望 |
|---|---|---|---|
| TC-S1-10 | 表格渲染 | 视图 | 接口返回的行出现在 DOM；`#empty` 槽在无数据时渲染 `EmptyState` 而非空白 |
| TC-S1-11 | 批量勾选接线 | 视图 | 勾一行 → 批量条出现且计数正确；表头全选只作用本页，再点一次全部取消（FR-v0.2-35 跨页保留由 `useSelection.spec.ts` 覆盖，视图只验接线） |
| TC-S1-12 | 行选中与详情联动 | 视图 | 点「查看日志」后打开对应行面板，`row-active` 高亮**只落在该行**（否则用户会对着 A 行读 B 行日志） |
| TC-S1-13 | 状态双编码 | 视图 | 状态列渲染 `StatusTag`，每个徽标内都有 `svg` 图标；终止态行不渲染「取消」 |

**两条固定套路**（后续写视图测试直接用）：

1. `vi.mock` 会被提升到 import 之前 —— 工厂里引用外部 `const` 会 TDZ 报错，假数据必须写进工厂内部。
2. 组件若用 `<RouterLink v-slot="{ navigate }" custom>`，不装整个 vue-router，注册一个
   「把 `navigate` 交给默认插槽」的桩即可；`setup` 的 slots 要标注为 `Slots` 类型，否则 `unknown`
   传给 `h()` 会 TS 报错。
