### 3.2b UX-04b（逐页迁移）· 视图级回归测试（2026-11-05 追加）

逐页把原生元素换成库组件，**四态截图只能人看，而人看不覆盖「接线」**：迁移中最容易坏的不是样式，

视图级 spec，用 `createApp(CasesView).mount(div)` 真挂载（不引入 `@vue/test-utils`）。

**十条固定套路**（后续写视图测试直接用；8~10 条来自 UX-05 表格壳）：

1. `vi.mock` 会被提升到 import 之前 —— 工厂里引用外部 `const` 会 TDZ 报错，假数据必须写进工厂内部。
   需要在测试里改返回值时用 `vi.hoisted()` 建一块可变状态，工厂函数在**调用时**才读它。
2. 组件若在**模板里**用 `<RouterLink v-slot="{ navigate }" custom>`，不装整个 vue-router，注册一个
   「把 `navigate` 交给默认插槽」的桩即可；`setup` 的 slots 要标注为 `Slots` 类型，否则 `unknown`
   传给 `h()` 会 TS 报错。
3. 若在**渲染函数里**用 `h(RouterLink, ...)`，上面的 `app.component` 桩**换不掉它** —— 那是模块导入的
   组件实例，会去读 router 上下文的 `currentRoute` 并崩在 vue-router 内部
   （`Cannot read properties of undefined (reading 'resolve')`）。必须模块级 `vi.mock('vue-router')`。
4. `NTabPane` 的标题取的是 **`children.tab`（即 `#tab` 插槽）**，只给 `:tab` prop 会渲染出
   **空白的页签标签且无任何报错** —— 页签在、字没了。迁移 Tabs 时务必用 `#tab` 插槽并断言标签文字。
5. **`NSelect` / `NRadioGroup` 不能 `v-model` 到窄类型 ref**：两者的 `value` 是
   `string | number | null`（`NRadioGroup` 还可能是数组），`v-model:value` 到 `ref<'day' | 'week'>`
   会被 `vue-tsc` 判成不兼容赋值。用 `:value` + `@update:value`，并在**一个 setter 里**收敛
   （`value === 'week' ? 'week' : 'day'`），别在模板里撒 `as`。
6. **`NDataTable` 的列宽是数字（`width: 120`），不带 `px`**，因此不会命中
   `tools/check_tokens.py` 的 px 白名单；但**模板内联** `style="width: 220px"` 会被扫到。
   需要固定宽度时写成 scoped class（既过守门，也避免同一数字散落多处）。
7. **递归组件的测试用 `h()` 建包装组件，别写字符串模板** —— 字符串模板依赖运行时编译器，
   vitest 里能不能用取决于解析到哪个 vue 入口；`h(Comp, { onFoo: cb })` 既不依赖编译器，
   emit 监听也直接落在 props 上。**扩守门的扫描范围时，必须同时交一份"注入缺陷"的负向证据**
   （如 `neg-tree-toggle.py`）：范围变大本身没有可观测产出，不注入就无法证明不是假绿。
8. **泛型壳的模板里不能写 `as` 类型断言**：`<script setup generic="T extends object">` 之后，
   模板表达式的类型收窄没法用 `(row as {id: number}).id` —— `vue-tsc` 直接报
   `TS1109 Expression expected`。断言要搬进 script（如 `resolvedRowKey` computed），模板只引用结果。
9. **`check_icons.py` 的 `\bicon=` 会误吃 `:icon="expr"`** —— `\b` 在 `:` 与 `i` 之间成立，
   变量名就被当成未定义图标名。已加 `(?<!:)` 后顾并补自检用例。守门误报的代价和漏报一样高：
   它会逼人改对的代码。
10. **`calc(100vh - Npx)` 里的 px 也受白名单管**：新写一个 `360px` 会被 `check_tokens.py` 拦，
    要么复用已有档位（本轮用 340px），要么显式评审后加白名单。别用「反正是 calc」绕过。
