**首要缺口（P0）**

1. **租约未接入执行链路**：`LeaseService.acquireAll` 全仓只有单测调用，`RunExecutionService`
   仍是「W2 最小闭环（无租约服务）」。连带 FR-04 / 07 / 08 / 09 / 10 / 23 全部降为「部分」：
   租约页恒空、强制释放恒 404、取消释放无对象。→ 建议 **EXEC-09**。
2. **队列语义与承诺不符**：`SerialRunDispatcher` 全局单线程（`MAX_PARALLEL` 只用于入参校验），
   入队列表按 `enqueued_at` 而非 `priority`。FR-03 / 05 需要「改实现」或「改口径」二选一。

**次级缺口（P1）**：设备范围字段缺失（FR-01）、单用例超时缺失（FR-24）、
重试次数未在运行详情展示（FR-29）、日志过滤只有「只看失败」一档（FR-20）。
