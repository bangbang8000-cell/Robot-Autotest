## 2. B6 的决定摘要

- **自动基线**：仍限同 `DUT`/`LINK`（现状不变，避免默认口径漂移）。
- **手动基线**：**允许跨 `DUT`/`LINK`**，但必须显式选择 + 结果带 `crossEnvironment=true`
  与两侧 `DUT`/`LINK` + 页面与导出件显示「跨环境对比，仅用于排障参考，不得作为验收基线」。
- **仍 400 的只剩**：基线不存在、基线不属于当前项目。
- **现状差异（必须如实说）**：代码当前仍对跨 `DUT`/`LINK` 的手动基线返回 400
  （`CompareService.java:166-183`，`raw/verify.txt` 第 6-9 行）。实现项 W-B6-1~4 未落地前，
  **对外一律按「暂不支持跨环境手动基线」表述**。

## 3. B7 的决定摘要

`run.started_at = NULL` 时：展示 `—`（能区分则 `—（未开始）` / `—（历史缺失）`）、排最后、
时长显示 `—`、趋势跳过、筛选显式排除、导出留空，**任何位置禁止出现 `Invalid Date` / `1970-01-01`**；
每个展示该字段的组件至少 1 条 `null` 断言。

## 4. 遗留

- B6 只有口径，没有实现；排期见 ADR-0008「实现项」表（W-B6-1~4）。
- B7 的约定要求「每个组件至少 1 条 null 断言」，本轮只核了 `format.spec.ts` 的公共格式化函数；
  `RunsView` / `ReportDetailView` 组件级 null 断言未逐个数，属遗留（未伪造计数）。
