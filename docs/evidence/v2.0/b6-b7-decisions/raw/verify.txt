## 10. 空值显示口径（`started_at` 为 `NULL` 等）

> 2026-11-07 定案（对应 `06-收口执行计划-20261106.md` §4 **B7**）。背景：`run.started_at`
> 在「已创建未开始」的 run 上天然为 `NULL`，历史迁移数据也可能缺失；若前端把它当
> `new Date(null)`（= 1970-01-01）或 `"Invalid Date"` 展示，会直接污染排序、时长与导出件。

- **展示**：`NULL` 一律走 `formatDateTime(value, fallback)`，fallback 用 `—`；
  **禁止**把 `NULL` 传进 `new Date()` 后再格式化。
- **区分原因**（能区分时）：未开始的 run 显示 `—（未开始）`；已结束但缺失显示 `—（历史缺失）`。
  分不清就只显示 `—`，**不猜测**。
- **排序**：`NULL` 排最后，不按 1970 参与升/降序。
- **时长**：`started_at` 或 `finished_at` 任一为 `NULL` → 时长显示 `—`，不显示 `0s`、不显示负值。
- **图表 / 趋势**：`NULL` 点跳过，不插 0、不连线跨过缺失点（与 FR-v0.5-20 一致）。
- **筛选**：时间范围过滤时 `NULL` 不落入任何区间（显式排除，不靠数据库隐式转换）。
- **导出**（CSV / PDF / Word / MD）：保留空单元格或 `—`，**禁止**出现 `Invalid Date`、`1970-01-01`。
- **测试**：每个展示 `started_at` 的组件至少 1 条 `null` 断言，且断言结果不含
  `Invalid Date` / `1970`。
