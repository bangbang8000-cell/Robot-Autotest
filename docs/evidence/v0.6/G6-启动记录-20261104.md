## 3. ADR-0013 禁跑令确认

挂起时 `execution_plan` 仅有 1 条且 `status=paused`，启用调度器后 **tick 领不到任何计划**，
不会产生真实 run，**触发样本为 0**，不违反「G5 通过前禁止在真实 DUT / 交换机执行台账用例」。
`EXE-07` 用合成用例、`EXE-08` 只做只读采集的约束不变。

## 4. 判定边界与归档

- 提前观测期记录的是「调度器常驻 / 服务不重启 / 配置不丢 / 禁跑令未被突破」，
  **不是定时触发成功率**；enabled 计划为 0 时触发样本为 0，**不计入正式 7 天**。
- **正式计时启动条件**：G5 通过当天，创建一个指向合成用例的 enabled 每日计划，
  并把当天记为第 1 天；届时把 `~/acc-g6/daily/` 的逐日记录归档进 `docs/evidence/v0.6/`。
- 若中途服务重启导致 `NRestarts>0` 或调度参数丢失，逐日记录会显式暴露，便于当场判阻塞。
